---
description: Fetch and display WordPress content summary
---

Synchronize and check WordPress content by:

1. Fetching posts from the WordPress API
2. Fetching projects (custom post type)
3. Fetching pages
4. Displaying a summary of available content:
   - Total number of posts, projects, and pages
   - List of recent posts with titles
   - Any errors or missing content

This helps verify that all WordPress content is accessible and properly configured.
